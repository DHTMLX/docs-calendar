# hideEventInfo()

### Description

@short: Hides an info popup window

### Usage

~~~jsx {}
hideEventInfo(): void;
~~~

### Example

~~~jsx {6}
// create Event Calendar
const calendar = new eventCalendar.EventCalendar("#root", {
    // configuration parameters
});
// hide an info popup
calendar.hideEventInfo();
~~~
